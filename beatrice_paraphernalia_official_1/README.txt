# Beatrice 2.0.0-rc.0 公式モデル 1 利用規約

Project Beatrice は、利用者が本規約に同意し、これを遵守することを条件として、利用者に対し無償で本モデルを提供します。

## 共通

### (本モデルの利用)

- 利用者は、本モデルに依存して音声の変換を行うために必要な範囲で本モデルを利用できます。
- 利用者は、前項以外の目的で本モデルまたはその改変物を利用できません。前項以外の利用には、パラメータファイル (.bin)、ポートレート画像その他同梱されたファイルの第三者への譲渡、貸与および再頒布が含まれます。

### (免責)

- 本モデルの使用による利用者の不利益に対して、Project Beatrice およびその関係者は一切の責任を負いません。

### (変換音声の利用)

- 本モデルによって生成された音声 (以下「変換音声」とします) の利用には、次条以下に定める目標話者別の規約が適用されます。
- 本モデルを読み込むソフトウェアの機能や不具合などによって、あるいは目標話者設定の切り替え直後などに、入力音声がソフトウェアの表示と異なる声質や複数の目標話者の中間的な声質に変換される場合があります。そのような変換音声を利用する場合、その声質に影響を与えたと考えられる全ての目標話者の規約に従う必要があります。

## つくよみちゃん®

### (禁止事項)

- つくよみちゃんの声質へ変換した変換音声を以下の目的で利用することを禁じます。
  - 人を批判・攻撃すること。（「批判・攻撃」の定義は、[つくよみちゃんキャラクターライセンス]( https://tyc.rei-yumesaki.net/about/terms/ )に準じます）
  - 特定の政治的立場・宗教・思想への賛同または反対を呼びかけること。
  - 刺激の強い表現をゾーニングなしで公開すること。
  - 他者に対して二次利用（素材としての利用）を許可する形で公開すること。

### (備考)

- つくよみちゃんは、夢前黎®氏がプロデュースするバーチャルキャラクターです。キャラクターを利用する際は[つくよみちゃんキャラクターライセンス]( https://tyc.rei-yumesaki.net/about/terms/ )を確認してください。
- 変換音声をつくよみちゃんの声として利用しない場合、クレジット表記は不要です。
- 本モデルの学習には、夢前黎氏が無償で公開されている「[つくよみちゃんコーパス]( https://tyc.rei-yumesaki.net/material/corpus )」および「[つくよみちゃんUTAU音源]( https://tyc.rei-yumesaki.net/material/utau )」を使用しています。
